Install HARDPLAY

Keep HARDPLAY in your Dock and open it in its own app window.

  1. Safari on macOS Sonoma or later
    Open this page in Safari. Choose File → Add to Dock, then Add.
  2. Chrome / Edge
    Use Install web app above when offered, or the browser’s install app icon in the address bar.
  3. Prepare for offline playback
    Open the installed app online. Add your tracks, wait for App saved and Saved offline on every track. In offline storage, choose Keep offline storage, then test the set without a connection.

Keep the same browser profile. The installed web app uses browser storage; clearing site data removes cached audio. The native Mac app and web library are separate.

Offline storage

Keep this app open while downloading. Only fully saved audio is ready offline. Clearing site data removes downloads. This cache belongs to this browser and device.

Keyboard / MIDI

Enable Map, choose an action here or a highlighted player button, then press a key or MIDI button.

MIDI is optional. Keyboard mappings work while this app is focused.

Trigger = once · Toggle = On / Off. A MIDI CC fader can control Master Volume.

Track timing

Leave empty for the full track, or enter m:ss / seconds. This sets the playback end point from the start of this queue item; it does not loop or stretch audio.
