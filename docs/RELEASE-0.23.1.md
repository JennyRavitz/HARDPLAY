# Hard Play 0.23.1 — PATCH Rear Panel

- PATCH is a dedicated rear panel for settings and locks. Hold the narrow strip to the right of the Main/Mini audio displays for three seconds to slide it out. A short press, early release or drag outside the strip cancels opening. The clearly labelled corner PATCH button provides immediate access and remains available while controls are locked.
- PATCH groups control lock, circular unlock, setup lock, Mini position lock and access to the complete settings panel. Status text distinguishes locked/available controls. Closing PATCH leaves playback and protection states unchanged.
- The large automatic unlock overlay no longer obscures toolbar buttons. The circular unlock control is shown inside PATCH when needed. Existing three-second keyboard unlock remains available after focusing it.
- Split Main/Mini toolbars into two spaced rows. Mini, Nano and Full Screen remain visible in the main toolbar, with layout, Auto Fit, undo, minimize and menu-bar access on the second row. Header logos remain removed.
- Settings is now labelled PATCH in the app menu, utility window and workspace tab. Command-comma still opens the full settings panel. Existing window-destination preferences and quick-button assignments remain valid.

macOS 14+, Apple Silicon. Ad-hoc signed, not notarized. Native app update; hosted web player unchanged.
