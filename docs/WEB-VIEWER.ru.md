# Web Viewer — плейлист на другом экране

В HARDPLAY откройте **Settings → Web Viewer…** (или пункт Web Viewer в меню приложения) и нажмите **Start Web Viewer**. Основное окно остаётся открытым.

Телефон или другой компьютер должны быть в одной Wi-Fi / Ethernet-сети с Mac. Сканируйте QR-код либо нажмите **Copy Link** и откройте полную ссылку в браузере второго устройства. Если Mac имеет несколько сетевых адресов, выберите адрес нужной сети. **Open Viewer** открывает локальный просмотр на самом Mac.

Экран показывает название сета, текущий и следующий трек с номерами, прошедшее и оставшееся время, очередь, состояние Play / Pause и кроссфейда. Неизвестная длительность обозначается прочерком. При потере связи данные тускнеют, появляется **Connection lost**, и последняя полученная позиция больше не выдаётся за актуальную. Подключение восстанавливается автоматически, пока текущая сессия включена.

Это просмотр без управления и передачи аудио. Веб-экран не отдаёт исходные файлы и локальные пути. Ссылка содержит случайный ключ доступа; любой получивший её может видеть сет до отключения просмотра. **Stop Sharing** закрывает сервер и отзывает ссылку; при новом запуске создаётся новый ключ. Окно настроек можно закрыть, не останавливая просмотр. Автоматического включения при запуске программы нет.

Соединение использует локальный HTTP: выбирайте доверенную сеть. Доступ через интернет, облако, гостевую сеть с изоляцией клиентов и VPN автоматически не настраивается. При первом системном запросе разрешите HARDPLAY доступ к локальной сети. Mac и приложение должны оставаться включёнными; сон Mac останавливает обновления.

Статус этой тестовой версии: работа с реальным плеером подтверждена на localhost. Проверка по сетевым IP на текущем Mac завершилась тайм-аутом; причина ещё не установлена. Успешное подключение физического телефона или второго компьютера пока не подтверждено.

Кнопка **Show button hints** включает фиксированную область **HINT** сверху окна HARDPLAY. Подсказка меняется при наведении и не накладывается на управление. У каждого окна своя область подсказок.

Проверка: `build/HARDPLAY.app/Contents/MacOS/HARDPLAY --viewer-test`. Тест использует синтетический сет, проверяет настоящий локальный HTTP-запрос, обновление времени и Pause, ключи доступа, отзыв старого ключа, ограничения запросов и отсутствие путей к аудио. Реальный телефон в другой сети требует отдельной проверки на используемом оборудовании.
