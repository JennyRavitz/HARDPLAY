# HARDPLAY 0.13.0

- Resizable native main window and one-click wide layout.
- Wide workspace with playback on the left and the embedded playlist on the right.
- Explicit In Player / Separate Window playlist controls.
- Web wide-layout preference survives reopening; narrow screens retain a vertical layout.
- Install on Mac panel with browser installation prompt when supported and Safari Add to Dock instructions.
- Ordinary native Dock icon plus menu bar access.
- Apple Silicon DMG / ZIP, checksums, full source and installation/build documentation.

Requires macOS 14+. The provided native binary is arm64, ad-hoc signed and not Apple notarized. Native and web audio libraries remain separate. Browser-managed storage is subject to eviction and clearing.
