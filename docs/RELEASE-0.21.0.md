# HARDPLAY 0.21.0 — Marker & Tape

- Approved blue three-beam identity replaces the red app/header/menu-bar keycap.
- Clear, upright Balsamiq Sans Bold hand lettering, bundled for offline use.
- Bundled offline marker typography across the player, playlist, pocket, settings, mappings and audio editor.
- Hand-inked vector control icons with existing action names and gestures.
- Tape Blue, Tape White and Tape Black presets with automatic light/dark ink contrast.
- Single-line HARDPLAY and stacked HARD / PLAY wordmarks; six self-contained SVG assets included.
- Native menu-bar symbol uses a simplified monochrome beam mark with playback state.
- Matching offline web-player source and local Web Viewer styling. This release does not redeploy the hosted Site.

- Embedded playlist grows the main window while keeping its top edge on screen; short displays can scroll the controls.
- Both deck waveforms show hover time. Click/drag seeks NOW or sets a one-shot NEXT cue; double-click starts playback from that point. Cues also work with automatic transitions and crossfades.

Native build/self/queue/style/waveform, clip, viewer, playlist, mapping and button-mode validation passed. Web tests/build passed. See VALIDATION.md for UI evidence and existing LAN-viewer limitations.

macOS 14+, Apple Silicon. DMG/ZIP and SHA-256 checksums. Ad-hoc signed, not notarized.
