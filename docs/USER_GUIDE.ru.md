# HARDPLAY

Нативный плеер для macOS 14+ на SwiftUI/AppKit. Версия 0.13.0: компактный сценический интерфейс, голубой/белый тейп и прозрачный фон с системным размытием.

## Управление

Откройте `build/HARDPLAY.app`. Приложение остаётся в строке меню при закрытом основном окне.

- Две деки показывают текущий и следующий трек, номера очереди, время и реальные звуковые волны. Во время crossfade слева остаётся уходящий трек, справа виден входящий; проценты и шкалы соответствуют коэффициентам наложения.
- Волны вычисляются из декодированного PCM в фоне; память ограничена 24 контурами по 160 отсчётов. Недоступная волна не препятствует воспроизведению.
- Основные кнопки: назад, Play/Pause, вперёд, «С начала», «Продолжить». Ползунок под деками меняет позицию текущего трека.
- «Переход» задаёт режим после текущего трека: без crossfade, короткий (3 с), долгий (6 с). «Ко всем» применяет выбранный режим ко всей текущей очереди.
- В строке очереди меню справа позволяет отдельно задать переход или убрать файл. Правый клик по строке открывает дополнительные действия. Удаление из очереди не удаляет сам файл.
- Кнопка настроек в заголовке открывает громкость, повтор, случайный порядок, запуск с начала/с места и остановку в конце или за 1–30 секунд до него.
- Мини-плеер включается соседней кнопкой в заголовке; остаётся поверх окон и на разных рабочих столах. Полный список доступен через «Треки» → «Вся очередь».
- Файлы и папки добавляются кнопкой +, через ⌘O, меню строки Mac или перетаскиванием.

## Плейлисты и подсказки

Интерфейс приложения и системные диалоги — на английском. Имена ваших файлов сохраняются без перевода.

Меню с названием плейлиста открывает Save Playlist (⌘S), Save Playlist As (⇧⌘S), Open Playlist (⇧⌘O) и недавние плейлисты. Файл `.hardplay` хранит порядок треков, позиции, переходы и режимы воспроизведения; аудиофайлы в него не копируются. Относительные пути позволяют переносить плейлист вместе с папкой музыки. Отсутствующие файлы остаются в списке с предупреждением. При открытии воспроизведение остаётся на паузе.

Settings → Show button hints включает описания при наведении. По умолчанию подсказки выключены; настройка сохраняется. Основная круглая кнопка Play/Pause увеличена и выделена полупрозрачным голубым фоном. Подсказки не перехватывают клики и скрываются под замком.

Пустой файл (0 байт) получает отдельное сообщение. При ошибке кнопка остаётся Play; повторная попытка проверяет выбранный файл заново. Звук из пустого файла восстановить невозможно — нужна полная копия исходной записи.

## Громкость и Keyboard / MIDI

Master Volume доступна прямо под кнопками транспорта: ползунок и процент 0–100. Регулятор управляет общим уровнем обеих дек при crossfade и запоминается.

Settings → Keyboard / MIDI или ⇧⌘M открывает панель назначений. Включите Map, выберите действие в списке либо нажмите подсвеченную кнопку плеера, затем нажмите сочетание клавиш или MIDI-кнопку. Выбор в режиме Map не исполняет действие. Esc отменяет ожидание; выключите Map для обычного управления. Закрытие панели также выключает Map.

Панель показывает Keyboard / MIDI для каждого действия и список доступных MIDI-входов. Назначаются транспорт, переходы, громкость, окна, блокировки и конкретные треки. Note On и CC-кнопки срабатывают при нажатии; отпустите кнопку для повторного срабатывания. Master Volume принимает непрерывный MIDI CC (0–127 → 0–100%). Volume Up / Down принимают клавиши и MIDI-кнопки.

Клавиши без модификаторов работают в HARDPLAY и не срабатывают при вводе текста. Сочетания с Option/Control/Command регистрируются как системные горячие клавиши; число успешно зарегистрированных видно внизу панели. Занятое системой сочетание остаётся доступным внутри приложения с сообщением. Штатные ⌘-команды и ⌥⌘ Space зарезервированы. Реальная доставка глобальных сочетаний зависит от системных конфликтов; физический MIDI-контроллер требует отдельной проверки.

Меню с именем набора позволяет Save Set / Open Set (JSON). Назначения автоматически сохраняются локально. Конфликтующее назначение одного сигнала переносится на новое действие с уведомлением; Clear Keyboard / Clear MIDI доступны по правому клику на назначении. Импорт проверяет версию и корректность до изменения действующего набора. Во время полного замка назначения не исполняются; снятие замка остаётся свайпом/удержанием. Защита Setup Lock продолжает блокировать выбранные действия.

## Trigger / Toggle и защита настроек

После назначения клавиши или MIDI-кнопки под её полем доступен выбор поведения. Trigger однократно выполняет действие: например, включает shuffle и повторным нажатием оставляет его включённым. Toggle переключает реальное состояние функции On/Off. Клавиатура и MIDI могут иметь разные режимы для одного действия; изменение функции мышью сразу учитывается следующим нажатием. Поддерживаются Play/Pause, Mute, Shuffle, Repeat, Stop at End, Short/Long Fade, окна, Setup Lock и конкретные треки. Mute возвращает прежнюю громкость; она сохраняется между запусками.

Next/Previous, Restart/Resume, Apply to All и пошаговое изменение громкости остаются Trigger. Master Volume работает непрерывно по CC. Полный Control Lock остаётся однократным включением с разблокировкой свайпом/удержанием. Режимы хранятся в наборах версии 2; старые наборы версии 1 загружаются с прежним поведением.

Замок в Audio & Playback и Keyboard / MIDI защищает настройки и назначения, оставляя кнопку Unlock Settings доступной. В Edit → Protect your setup можно включить Settings & mappings среди выбранных групп защиты. Под защитой нельзя менять назначения, режимы кнопок или загружать наборы; действующие назначения продолжают исполняться в пределах остальных выбранных ограничений. Полный замок интерфейса действует отдельно.

Rename — карандаш, Fade — значок волны с длительностью, Remove — корзина, Detach — стрелка из квадрата, Attach — звенья цепи. Основные кнопки используют символы; контекстные меню сохраняют читаемые подписи, доступные имена и значки. Карандаш и корзина — тонкие значки без плашек, при наведении становятся ярче. Удаление из очереди не удаляет аудиофайл.

## Названия треков

Карандаш справа в строке позволяет изменить название; Rename Track также доступен через меню перехода и правый клик. Название редактируется прямо в строке без отдельного диалога: Enter, галочка или потеря фокуса сохраняют, Esc отменяет. Use Filename в меню возвращает исходное имя. Новые названия отображаются во всех окнах, сохраняются в текущей сессии и через ⌘S в `.hardplay`. Аудиофайлы на диске не переименовываются. Защита редактирования блокирует и переименование.

Текст названий увеличен: в списке до 15 pt, на деках до 16 pt (13 pt в мини-плеере), с переносом на две строки.

## Отдельное окно плейлиста

В раскрытом My Set мини-плеера нажмите Detach. В большом окне выберите My Set → Detach Playlist. Откроется самостоятельное окно HARDPLAY Playlist: его можно перемещать, менять размер и держать поверх других программ. Оно использует ту же очередь и настройки защиты, без копирования треков.

Attach → Attach to Mini Player возвращает список в выпадающий My Set мини-плеера; Attach to Main Player возвращает очередь в большое окно. В отдельном режиме My Set мини-плеера повторно открывает самостоятельное окно, а в большом окне появляется Open Playlist Window. Закрытие отдельного окна не меняет режим и не останавливает музыку. Режим и положение окна сохраняются между запусками.

## Мини-очередь и защита настроек

В мини-плеере My Set раскрывает очередь: номера, названия треков и отдельные переходы. Внизу доступны меню сохранения/открытия и Full Queue. Edit Queue открывает большое окно.

В большом окне Edit позволяет выбрать группы защиты: Playlist edits & fades (добавление/удаление файлов, открытие другого плейлиста и изменение переходов), Track selection & skip (выбор трека и предыдущий/следующий), Playback & seeking (Play/Pause, Restart/Resume и перемотка). Lock Setup закрепляет выбор; Unlock снимает защиту. По умолчанию защищены первые две группы, а транспорт доступен. Защита действует одновременно в большом/малом окне, меню треков и командах с клавиатуры. Автоматическое воспроизведение и переходы продолжаются. Выбранные группы запоминаются, сама блокировка после перезапуска снята.

## Замок

Кнопка замка или ⌘L блокирует все поверхности управления, добавление файлов и команды воспроизведения с медиаклавиш/глобального сочетания. Музыка, визуализация и автоматические переходы продолжаются. Это защита от случайных действий, а не парольная защита.

Для разблокировки протяните большой голубой ползунок вверх на 60 точек. Альтернатива — удерживайте пробел, Enter или сам ползунок около секунды. Простое короткое нажатие не разблокирует. Используется нативная обработка мыши: свайп не перетаскивает окно. Для VoiceOver предусмотрено отдельное действие разблокировки.

## Сохранение и звук

Очередь, режимы переходов, позиции файлов и громкость хранятся локально. Позиции обновляются каждые две секунды и при паузе/переключении. Повторный запуск остаётся на паузе; замок после запуска отключён.

Во время crossfade работают два AVPlayer с дополняющими коэффициентами громкости. Пауза останавливает оба, перемотка прекращает исходящий поток. Режим остановки запрещает автоматический crossfade. На коротких файлах наложение ограничивается доступным остатком и половиной входящего трека. После последнего файла перехода нет без включённого повтора.

## Форматы

AVPlayer использует кодеки macOS: MP3, AAC/M4A, WAV, AIFF, ALAC, FLAC, CAF и другие системно доступные форматы. OGG/Opus, WMA и APE допускаются при добавлении, но сторонний универсальный декодер пока не встроен. Поддержка зависит от кодека конкретного файла. Облачные файлы должны быть загружены локально.

## Сборка и проверки

Нужен Apple Command Line Tools; внешних зависимостей нет.

```sh
./scripts/build.sh
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --button-mode-test
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --mapping-test
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --playlist-test
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --audio-probe /absolute/path/to/audio.wav
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --waveform-test /absolute/path/to/audio.wav
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --playback-test /absolute/path/to/12-second.wav /absolute/path/to/12-second.aiff
```

Сборка создаёт `.app` с локальной ad-hoc подписью и запускает self-test модели и порогов разблокировки. Playback-test проверяет прежнее воспроизведение, crossfade, две деки, продолжение под замком, массовые режимы и восстановление. Для бесшумной проверки нужны два файла с тишиной длительностью не менее 12 секунд. Waveform-test читает файл без проигрывания; в ограниченной среде доступ к системному декодеру может быть запрещён.

Это локальная сборка без notarization. Автозапуск, перестановка очереди и скрытие у края экрана пока не реализованы.

## Версия 0.12.0 — очередь и управление окнами

- Один клик по названию только выделяет пункт. Отдельная кнопка ▶ запускает трек; для звучащего пункта она становится паузой. Большая Play на паузе запускает выделенный пункт. Выделение во время музыки не меняет активный трек.
- Правый клик → **Duplicate Track** создаёт независимый пункт сразу после оригинала. Файл аудио используется тот же; название, позиция, переход и MIDI-цель у копии отдельные. Дубли сохраняются в очереди и `.hardplay`, старые плейлисты продолжают открываться.
- Блок значков: ▶→ следующий / ▶Ⅱ автостоп, начало / продолжение при явном Play, **ALL 0 / 3s / 6s** назначает crossfade всей очереди. Индивидуальные переходы остаются в строках. Ранее сохранённый Short теперь означает 3 секунды.
- Кнопки **−** добавлены в основной плеер, мини-плеер, отдельную очередь и окно Keyboard / MIDI. Восстановление — через меню бар или повторное открытие приложения.
- Кнопка булавки привязывает плеер к меню бару; перечёркнутая булавка отсоединяет в свободный мини-плеер. Иконка остаётся в строке меню в обоих режимах. Слева — открыть/скрыть выбранное представление, справа — окна и переключение привязки.
- Иконка меню бара адаптируется к светлой/тёмной теме и показывает Ready / Playing / Paused / Crossfade / Error; подсказка содержит название и время. Это индикатор состояния, а не измеритель уровня сигнала.
- Дополнительная проверка модели очереди: `build/HARDPLAY.app/Contents/MacOS/HARDPLAY --queue-test`.

Веб-версия в `web/` также разделяет Select/Play, поддерживает контекстное дублирование, таймер каждого пункта и режимы 0/3/6 секунд. Меню бар macOS относится к нативному приложению.

Песни и папки можно перетаскивать из Finder прямо в отдельное окно плейлиста; основное окно открывать не требуется. Область приёма подсвечивается голубой рамкой. Новые файлы добавляются в общую открытую очередь без автоматического старта. Защита редактирования блокирует drop в обоих окнах.
