# Hard Play 0.23.0 — Personal Controls Preview

- Per-panel opening preferences: Inside Player, Nearby Window, Independent Window, Ask Each Time, or Workspace Default. Available for Settings, Themes, MIDI/Keys, Backup, Viewer and Audio Edit. Nearby panels follow the main player; independent panels retain their own position. A right-click on a settings/panel button offers a one-time destination and a saved default. The optional opening prompt can remember the choice.
- Optional custom quick buttons, up to four, below the toolbar. Configure in Settings and right-click to reassign an action, change Trigger/Toggle behavior where supported, or remove. Window actions, playback, transitions and individual track actions share the existing mapping/lock rules. Fixed transport controls retain their familiar actions.
- Expanded keyboard/MIDI action list includes utility panels, Nano, Auto Fit, Auto Nano, full screen and hints.
- Removed the header wordmark in Main and Mini; increased toolbar, restart/resume and transition-button spacing. The app and menu-bar icons remain.
- Lock Controls presents a clockwise circular unlock ring with a 60-point radius and visible progress. Short clicks, straight swipes, large jumps and counterclockwise motion do not unlock. Releasing early resets progress. Keyboard fallback: hold Space/Return for three seconds. Pocket has the same ring and a three-second drawer hold alternative.

macOS 14+, Apple Silicon. Ad-hoc signed, not notarized. This update changes the native app; the hosted web edition is unchanged.
