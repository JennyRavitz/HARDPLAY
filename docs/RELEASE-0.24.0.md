# Hard Play 0.24.0 — Crew Sets Preview

- New Playlist creates a named empty set. Delete Playlist moves a saved playlist document to the macOS Trash, or clears an unsaved set. Audio files remain untouched. Both commands are in Playlist Files, the set-name context menu and the app menu; Command-N opens New Playlist.
- New-set creation retains the previous queue in Undo, including the original saved-document binding. Undo after deletion restores the queue as an unsaved set; the deleted document remains recoverable from Trash. Failed deletion leaves the current set intact. Setup and control locks protect these actions.
- The Main toolbar now uses a dedicated marker-on-tape mini hardplay button, with the previous clear font retained for track names and controls. The bundled marker font adds approximately 75 KB of uncompressed resources; its license is included.
- New FOH, Stage Crew and Stagehand themes: dark touring-case surfaces, metal edging, corner hardware, understated inventory marks and muted crew tape. The design uses static vector paths and system text; no new texture images, videos or continuously animated backgrounds.
- Themes remain selectable in PATCH → Themes & Appearance. Existing custom appearance preferences are preserved.

Design references: [FOH equipment and crew labels](https://rupertneve.com/live/garry-brown), [production rehearsal cases](https://tonylevin.com/road-diaries/peter-gabriel-io-tour/london-rehearsals-pt2). These are visual references, not affiliated branding.

macOS 14+, Apple Silicon. Ad-hoc signed, not notarized. Native app update; hosted web edition unchanged.
