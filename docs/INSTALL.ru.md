# Установка HARDPLAY на Mac

## Нативное приложение

1. Скачайте DMG или ZIP из GitHub Releases. Скачивание публичное, вход в GitHub не требуется. Нужна macOS 14+.
2. В DMG перетащите HARDPLAY в Applications. Для ZIP распакуйте архив и перенесите HARDPLAY.app в Applications.
3. Запустите через Applications или Spotlight. Иконка есть в Dock и в меню баре.
4. Добавьте локальную музыку кнопкой + или перетащите её в плейлист. Интернет для неё не нужен.

Текущий готовый пакет — для Apple Silicon. На Intel приложение можно собрать из исходников. Сборка имеет локальную ad-hoc подпись, без Apple notarization. При блокировке первого запуска используйте штатное подтверждение в System Settings → Privacy & Security → Open Anyway, только если доверяете скачанной сборке. Не отключайте системную защиту.

## Веб-приложение с офлайн-кэшем

1. Откройте HARDPLAY Web и войдите, если хостинг запрашивает доступ.
2. Нажмите Install on Mac внизу. Safari: File → Add to Dock → Add. Chrome / Edge: установка приложения через браузер или Install web app, когда кнопка доступна.
3. Откройте установленное приложение онлайн. Добавьте файлы с Mac или скачайте их по облачной ссылке.
4. Дождитесь App saved и Saved offline для всех треков. В панели офлайн-хранилища запросите Keep offline storage.
5. Перед выступлением проверьте открытие и воспроизведение набора без интернета.

Веб-кэш привязан к профилю браузера. Очистка данных сайта удаляет аудио. Плейлист JSON содержит настройки, а не звук. Между нативным приложением и веб-версией библиотека автоматически не переносится.

## Окна

↔ включает широкую компоновку. На Mac размер также меняется за края основного окна. In Player возвращает список внутрь; Separate Window выносит его отдельно. В отдельной очереди значок цепи возвращает её к плееру. Изменение компоновки не запускает треки.
