# Подготовка резервного Mac — первый этап

Локальная версия 0.17.0 добавляет **Settings → Timecode & Backup…**. Это подготовка пары и проверка сета. Совместный запуск, LTC/MTC и автоматический выбор аудиоисточника ещё не включены. Проверенное совпадение файлов не означает синхронизацию аудиовыходов.

## Соединение

1. Подключите оба Mac к одной локальной сети; для сцены предпочтительно проводное соединение. Интернет не требуется.
2. На основном Mac выберите **Primary A → Create Pair**. На резервном — **Backup B → Find Mac**.
3. Введите на резервном 12 символов кода с основного Mac и нажмите **Connect** возле найденного компьютера. Код действует пять минут для создания соединения; он не сохраняется в настройках.
4. Если Bonjour недоступен, раскройте **Connect by IP** и укажите адрес основного Mac и показанный порт. Разрешение Local Network и системный firewall должны позволять связь.

Одна пара использует TLS 1.2 PSK / AES-128-GCM с ключом из временного кода. Не передавайте код посторонним. Коды не переиспользуются; отсутствие forward secrecy у этого PSK-набора учитывается для будущего перехода на TLS с индивидуальными сертификатами. [Ограничение Network.framework PSK](https://developer.apple.com/documentation/technotes/tn3213-moving-from-multipeer-connectivity-to-network-framework). Приложение не слушает сеть автоматически при запуске: только после Create Pair / Find Mac / Connect. На текущем этапе по соединению передаются сведения о сете и статус связи; аудио и команды воспроизведения по нему не передаются.

## Перенос и проверка

1. Поставьте воспроизведение на паузу и нажмите **Check This Set**. Файлы читаются в фоне; выполняются SHA-256, проверка длительности и пробное декодирование начала аудио. Это не полная проверка декодирования всего файла.
2. Если на втором Mac ещё нет сета, нажмите **Export Backup Package…** и выберите новое имя папки. Экспорт создаёт `Set.hardplay`, папку `Audio` и `BackupManifest.json`. Он не перезаписывает существующую папку. Аудио внутри пакета проверяется после копирования; дубликаты пунктов используют одну копию файла, сохраняя независимые пункты очереди.
3. Скопируйте всю папку на резервный Mac и откройте `Set.hardplay`.
4. Выполните **Check This Set на обоих Mac**. При соединении результаты передаются автоматически.

Сравниваются содержание и порядок аудио, длительности, переходы, On Play, Auto Stop, Shuffle / Repeat и позиции Resume. Пути и отображаемые названия могут различаться. Пункты сопоставляются по месту в очереди: локальные ID и пути не считаются переносимыми сетевыми идентификаторами.

При различиях показывается номер и причина: другой файл/порядок, переход, позиция и т. д. Изменение конфигурации сета сбрасывает проверку. Изменение размера/даты файла проверяется каждые две секунды и также сбрасывает результат. Для повторной проверки содержимого с неизменёнными метаданными нажмите Check This Set заново.

Надпись **Sets match · preparation only** означает совпадение проверенных сетов. При обрыве соединения она снимается. Плеер не останавливается, не переключает трек или аудиовыход. Автоматического переподключения и автоматического возврата на основной Mac пока нет.

Главное окно остаётся открытым при работе с Timecode & Backup. Когда пара активна или ждёт соединения, в основном окне появляется компактная строка статуса. Защита настроек и полный замок блокируют изменение конфигурации пары.

## Следующие этапы

См. [план](TIMECODE-BACKUP-PLAN.ru.md): планируемый старт от аудиочасов и измерение расхождения → LTC/MTC → независимый аппаратный A/B и аварийные испытания. До проверки двух физических Mac и аудиооборудования этот этап нельзя использовать как готовый сценический автоматический резерв.

## Проверки разработчика

```sh
zsh scripts/build.sh
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --backup-test
build/HARDPLAY.app/Contents/MacOS/HARDPLAY --backup-link-test
```

Первый тест создаёт собственный временный WAV и не проигрывает музыку. Второй дополнительно открывает соединение двух тестовых объектов через localhost; для него нужен разрешённый локальный сетевой доступ. Системный декодер аудио также может быть недоступен внутри ограниченного sandbox.
